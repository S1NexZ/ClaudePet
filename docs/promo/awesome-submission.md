Самый крупный список ресурсов по Claude Code (около 58 тыс. звёзд). Заявки принимаются **только через веб-форму**: за пулл-реквесты и автоматические заявки там временно блокируют. Поэтому заявку отправляете вы сами.

**Открыть форму:** https://github.com/hesreallyhim/awesome-claude-code/issues/new?template=recommend-resource.yml

**Условие:** проекту не меньше 14 дней, и он активно развивается (ccPet подходит), либо у него 100+ звёзд. За раз можно предложить только один ресурс.

**Description:**

> A free desktop pet for Claude Code (Windows, macOS, Linux) that watches your sessions through hooks and lets you act on them without switching windows. It animates what Claude is doing, shows Claude's AskUserQuestion prompts as clickable options (answered back through the PermissionRequest hook), can approve tool permissions, shares one live session with your terminal through a PTY wrapper, queues messages for the next turn or a set time (including right after the 5-hour limit resets), and shows a per-turn summary of changed files. Every change to settings.json is shown as a diff and backed up first.
