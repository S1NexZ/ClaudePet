# Сценарий демо-видео ccPet

Одно видео на 25–30 секунд, из него же нарезаются GIF для README и короткие ролики (TikTok, Shorts, Reels).

## Подготовка

- **Запись:** OBS Studio (бесплатно) или Win+Alt+R (Xbox Game Bar). 1920×1080, 60 fps.
- **Экран:** тёмная тема, чистый рабочий стол, в кадре только терминал с Claude Code и питомец. Уберите уведомления (режим «Не беспокоить»), закройте мессенджеры и вкладки с личным.
- **Шрифт терминала** покрупнее (16–18 pt), чтобы читалось с телефона.
- **Модель Claude:** Haiku или Sonnet, чтобы ответы приходили быстро.
- **Подготовьте папку-песочницу** с маленьким проектом и одним падающим тестом: тогда Claude починит его за один ход.
- **Питомец** в правом нижнем углу, размер 120–140 % (трей → «Размер питомца»).
- Заранее примените хуки и обёртку терминала, чтобы всё работало с первого дубля.

## Сцены

| # | Время | Что в кадре | Что происходит с питомцем |
|---|---|---|---|
| 1 | 0–3 с | Терминал, вы печатаете `claude "почини падающий тест"` | Питомец просыпается, «Думает» |
| 2 | 3–8 с | Claude читает файлы и правит код | Анимации «Читает» → «Пишет» |
| 3 | 8–12 с | Claude запускает тесты, сначала падение | Питомец грустит (реакция «тесты упали») |
| 4 | 12–17 с | Claude задаёт вопрос с вариантами (например, «Какой подход выбрать?») | Над питомцем «Вопрос», вы жмёте вариант прямо в питомце |
| 5 | 17–22 с | Тесты проходят | Питомец прыгает и машет, «Тесты прошли!» |
| 6 | 22–26 с | Открывается чат питомца с карточкой сводки (файлы, +/− строк, время) | Пока Claude ещё пишет, вы набираете сообщение, и оно встаёт в очередь «после ответа» |
| 7 | 26–30 с | Финальный кадр: обложка ccPet | Текст: «ccPet — free desktop pet for Claude Code · github.com/S1NexZ/ccPet» |

Чтобы Claude гарантированно задал вопрос в сцене 4, добавьте к задаче: «перед правкой спроси меня через AskUserQuestion, какой из двух вариантов исправления выбрать».

## Монтаж

- Ускорьте «скучные» места (ожидание ответа) в 2–4 раза, а моменты с питомцем оставьте в обычной скорости.
- Подписи на экране короткие, по 3–5 слов: «Shows what Claude is doing», «Answer Claude's questions», «Cheers when tests pass», «Queue your next task». Для русских площадок — те же по-русски.
- Звук: лёгкая музыка без слов (YouTube Audio Library, бесплатно). Для README звук не нужен.
- Если на питомце видна модель Claude-maiden, в описании видео укажите, что это встроенная модель стороннего автора (как в THIRD_PARTY_NOTICES.md).
