# Какие данные хранит ccPet и куда они идут

ccPet работает локально. Приложение **не отправляет телеметрию, не имеет аккаунта и не обновляется само**.

Единственный сетевой запрос самого ccPet — **проверка обновлений** раз в сутки: `GET https://api.github.com/repos/S1NexZ/ccPet/releases/latest` с заголовком `User-Agent: ccPet-update-check`, без каких-либо данных о вас (GitHub при этом видит ваш IP, как при открытии любой страницы). Если есть новая версия, питомец показывает уведомление и пункт в меню трея; скачивать и ставить её вы решаете сами. Выключается в меню трея: «Проверять обновления».

## Что и где хранится

### Windows: `%APPDATA%\Claude Pet\`
| Файл / папка | Содержимое |
|---|---|
| `settings.json` | автозапуск, уведомления, горячая клавиша, активная модель, цвета оформления |
| `window.json` | положение окна питомца |
| `pet.log` | журнал приложения (события запуска моста, ошибки; тексты ваших разговоров в него не пишутся) |
| `models\<id>\` | ваши установленные модели питомцев (файлы `pet.json`, лист спрайтов, при наличии `tweaks.json` и текстовые README/LICENSE) |
| прочее (`Cache`, `Local Storage` и т. п.) | служебные данные Electron |

Встроенная модель лежит в папке установки (`%LOCALAPPDATA%\Programs\claude-pet\resources\models`) и не меняется.

### WSL: `~/.claude-pet/`
| Файл | Содержимое |
|---|---|
| `hook.sock` | unix-сокет, в который хуки Claude Code шлют события о сессиях |
| `pty/<pid>.sock` | сокеты обёртки `pet-claude.py` (права 0600), существуют, пока жив терминальный процесс |
| `usage.json` | если подключена строка состояния Claude Code: проценты и время сброса окон 5 часов и недели (их присылает сам Claude Code) |
| `usage-query/` | пустая рабочая папка короткого процесса, который запрашивает лимиты |

## Что приложение читает у Claude Code
- **Транскрипты** `~/.claude/projects/**/*.jsonl` — только чтение: чтобы показать историю в чате, найти место возобновления сессии и заметить прерывание. Они остаются у вас, наружу не копируются.
- `~/.claude/settings.json` — читается, чтобы понять, подключены ли хуки; **изменяется только после вашего подтверждения** (показывается точный diff, делается копия).
- Учётные данные, токены и cookie ccPet не читает и не хранит. Запросы лимитов делает сам Claude Code (в короткоживущем процессе без вашего промпта и без загрузки пользовательских настроек и хуков); код ccPet токенов не видит.
- Процессы `claude`, которые запускает питомец (запасной путь отправки и запрос лимитов), обновляют `~/.claude.json` обычным для Claude Code способом (под блокировкой).

## Сеть
- Сам ccPet не обращается к сети. Исключения только по вашему действию: кнопка «Открыть пакет на npmjs.com» открывает страницу в браузере (разрешён фиксированный список адресов npmjs.com).
- Запросы к Anthropic идут от процессов Claude Code: ваших обычных сессий, запасного пути SDK и ежеминутного запроса лимитов.
- Модели из npm: ccPet не запускает npm. Сторонний `codex-pets` (если вы запускаете его сами) скачивает модели из своего каталога.

## Как всё удалить
Удалите программу (Параметры → Приложения), затем папки `%APPDATA%\Claude Pet` и `~/.claude-pet`. Блок `claude-pet` в `~/.bashrc` уберите командой `install-shell-integration.sh --uninstall` (до удаления программы) или вручную (строки между `# >>> claude-pet >>>` и `# <<< claude-pet <<<`). Хуки в `~/.claude/settings.json` (команды с `pet-hook.mjs`) удалите вручную; если файла хука нет, они ничего не делают.
