## ccPet 0.6.4 — исправления для Windows, macOS и Linux

- **Windows: отправка в чат приложения Claude снова идёт как ваше сообщение.** При свёрнутом окне приложения сообщение уходило через хук бледной вставкой (ошибки mismatch и no-send). Теперь окно на время ввода невидимо разворачивается и сворачивается обратно. Окно-«призрак» после прерванной попытки исправляется само.
- **Windows: питомец больше не пропадает под полноэкранными плеерами.** Флаг «поверх всех» переустанавливается каждые 2 с. Игры в эксклюзивном полноэкранном режиме перекрыть нельзя: включите «оконный без рамки».
- **macOS: «Приложение повреждено» исправлено.** Приложение подписано ad-hoc. При первом запуске: правая кнопка → «Открыть». Если macOS всё равно пишет «повреждено», выполните `xattr -cr /Applications/ccPet.app`.
- **Linux: AppImage запускается на Ubuntu 24.04 и новее** (раньше падал из-за песочницы Chromium). Для AppImage нужны `chmod +x` и `libfuse2`. На Ubuntu и Debian проще ставить .deb.

**Файлы:** `ccPet-Setup-0.6.4.exe` (Windows), AppImage и deb (Linux), dmg и zip (macOS: arm64 для Apple silicon, x64 для Intel).

**English:** Windows: sending to a Claude app chat works again with a minimized app window (was falling back to hook text); the pet stays above fullscreen players. macOS: ad-hoc signed, no more "app is damaged". Linux: the AppImage starts on Ubuntu 24.04+ (Chromium sandbox).
