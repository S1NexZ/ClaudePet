## ccPet 0.5.0 — десктоп Claude и Windows как «родные» сессии

**Десктопное приложение Claude**
- Сессии показываются под **названиями чатов**, архивные скрыты.
- **«Открыть»** открывает этот же чат в приложении Claude, без второго процесса `claude`.
- **«Стоп»** работает и здесь (а также в IDE и обычных Windows-терминалах): Claude останавливается после текущего шага.

**Windows**
- **Лимиты от Windows-сессий** через статус-строку (подключается в «Настройки → Подключения»; ваша строка сохраняется).
- **Обёртка `claude` в профиле PowerShell — одной кнопкой** (с показом изменений и копией файла). Она даёт Esc, «Стоп» и ввод из питомца.
- **«Открыть в терминале»** поднимает вкладку самой сессии вместо клона.
- **Новые чаты можно запускать в Windows** (выбор в «Подключениях»).
- Новые сессии (в том числе из VS Code) видны сразу, с меткой источника, и не теряются при перезапуске питомца.

**Диагностика:** время последнего события по каждому подключению и кнопка «Скопировать отчёт» (без имени пользователя и токенов).

**Исправлено**
- `claude -p "…"` больше не зависает, пока работает питомец.
- Панель сессий сворачивается вместе с чатом.

**Прочее**
- Встроенная модель Clawd убрана, по умолчанию Claude-maiden.
- Кружок статуса и кольцо лимитов одного размера.

**Установка / обновление:** скачайте `ccPet-Setup-0.5.0.exe` ниже и запустите. Настройки, модели и хуки сохраняются. Установщик не подписан: SmartScreen покажет предупреждение («Подробнее» → «Выполнить в любом случае»). После обновления откройте «Подключения»: если хуки Windows устарели, питомец сам предложит их обновить.

**English:** the Claude desktop app and Windows now work as first-class sessions: desktop chats show their titles, Open jumps to that chat in the app, Stop works for desktop/IDE/plain Windows terminals (after the current step). Windows sessions feed the limits ring via a status line; the PowerShell `claude` wrapper installs with one click; Open raises the session's own terminal tab; new chats can start on Windows. New sessions (incl. VS Code) appear at once and survive pet restarts. Connections show the last event per host and a copyable diagnostics report. Fixed: `claude -p` no longer hangs while the pet runs. Clawd removed; Claude-maiden is the default. Unsigned installer.
