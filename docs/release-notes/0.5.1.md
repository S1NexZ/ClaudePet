## ccPet 0.5.1 — точные лимиты, меньше нагрузки, проверка обновлений

**Исправлено**
- **Лимиты больше не откатываются назад.** Сессии без свежих ответов перерисовывали статус-строку со старыми цифрами и перетирали свежие. Теперь внутри одного окна лимита процент может только расти, а новое окно (после сброса) сразу заменяет старое.
- **Статус-строка Windows работает без Git Bash.** Раньше без Git Bash она молча не запускалась (Claude Code вызывает её через PowerShell). После обновления питомец предложит обновить строку — примите предложение.
- По итогам ревью кода: первое сообщение нового Windows-чата больше не может попасть в чужую сессию; профиль PowerShell пишется в правильной кодировке (раньше ломался путь с кириллицей); пути с пробелами; ожидатели не копятся, пока питомец закрыт; `-p` в тексте подсказки больше не путается с `claude -p`.

**Изменено**
- **Меньше нагрузки в покое**, внешне без изменений: около 3,4% всех ядер → 0,9–1,6% (отрисовка спит между кадрами, свечение — CSS-анимация, таймер анимаций замедляется, когда идёт только «дыхание»).
- **Цвет дуги и полос лимитов — ваш** (акцентный цвет из «Настройки → Цвета»), без автоматического жёлтого и красного. Кольцо показывает 5-часовой лимит, неделя — в подсказке.
- **pet-helper.exe работает из постоянной копии** `%LOCALAPPDATA%\ccPet\bin`, поэтому обновления ставятся и при открытых сессиях. При первом запуске питомец предложит обновить пути в подключениях.
- Подписи в статус-строке: `5h 43% · 7d 98%`.

**Добавлено**
- **Проверка обновлений** раз в сутки (публичный адрес релизов GitHub, без данных о вас): уведомление и пункт в меню трея. Ничего не скачивает само; выключается в меню трея.

Небольшое отставание лимита от claude.ai (около 1%) заложено в данных Claude Code: он отдаёт значение из ответа на предыдущий запрос. Самое свежее значение — по клику на кольцо.

**Установка / обновление:** скачайте `ccPet-Setup-0.5.1.exe` ниже и запустите. Установщик не подписан: SmartScreen покажет предупреждение («Подробнее» → «Выполнить в любом случае»).

**English:** limits no longer roll back (stale status line reports from idle sessions are ignored within a window); the Windows status line works without Git Bash; code-review fixes (new-chat prompt routing, PowerShell profile encoding, paths with spaces, waiter pile-up, `-p` detection); ~2–4x lower idle CPU with no visible change; the limits ring and bars use your accent colour; pet-helper runs from a stable copy so updates install while sessions are open; daily update check (notification only). Unsigned installer.
