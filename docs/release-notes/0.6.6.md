## ccPet 0.6.6 — безопасность и правила Anthropic

- **Безопасное открытие терминала.** Имя папки или текст первого сообщения с `;`, `&`, `|` больше не ломают запуск и не могут выполнить лишнюю команду. Заодно починено «Открыть в терминале» для WSL-сессий в Windows Terminal.
- **По правилам Anthropic** питомец больше не обращается к Agent SDK с вашим входом по подписке сам, при запуске: лимиты обновляются кликом по кольцу и от строки состояния Claude Code.
- **Очередь и `/at` не трогают окно приложения Claude** и не забирают фокус, когда вас нет за компьютером.
- Вопрос Claude исчезает из питомца, если сессию закрыли.
- Встроенный питомец теперь называется **cPet** (без «Claude» в названии, по правилам Anthropic о товарных знаках).

**Файлы:** `ccPet-Setup-0.6.6.exe` (Windows), AppImage и deb (Linux), dmg и zip (macOS: arm64 — Apple silicon, x64 — Intel).

**English:** safe terminal launching (a `;` `&` `|` in a folder name or prompt can no longer break the command or run another one; also fixes "Open in terminal" for WSL sessions in Windows Terminal); following Anthropic's rules, the pet no longer calls the Agent SDK with your subscription login on its own at start-up (limits refresh on your click on the ring and from the status line); queued and scheduled messages never drive the Claude app window; Claude's question disappears from the pet when the session closes.
