## ccPet 0.4.1 — безопасность использования и переименование

Проект теперь называется **ccPet** (раньше Claude Pet; «cc» — сокращение от Claude Code, это неофициальный проект, не связанный с Anthropic).

**Исправлены потенциально небезопасные способы использования** (с точки зрения правил Anthropic):
- **Нет фоновых запросов.** Регулярный опрос лимитов раз в минуту удалён. Теперь запрос выполняется один раз при запуске и по вашему клику на кольцо лимитов (не чаще раза в минуту). В фоне кольцо питается строкой состояния Claude Code, которую присылает сам Claude Code (подключается в «Настройки → Подключения»; ваша собственная строка состояния сохраняется и восстанавливается).
- **Agent SDK выключен по умолчанию.** Запуск второго процесса `claude` через Agent SDK (новые чаты из питомца, продолжение терминальных сессий, /btw, список моделей) включается отдельным флажком с предупреждением. Без него «новый чат» открывает новую сессию в терминале, а общение с запущенными сессиями идёт через хуки и обёртки.
- Токены и учётные данные питомец не читает и не хранит; на хуки и файлы Claude Code это не влияет.

**Что ещё нового с версии 0.4.0**
- Кольцо лимитов без цифры (цифры в подсказке), панель по клику с одним свежим запросом.
- Чат при повторном открытии стоит на последнем сообщении.
- Настройки не прокручиваются вверх после изменения.
- Название и файлы: `ccPet.exe`, `ccPet-Setup-0.4.1.exe`; настройки (`%APPDATA%\Claude Pet`), модели и подключённые хуки сохраняются при обновлении.

**Установка / обновление:** скачайте `ccPet-Setup-0.4.1.exe` ниже и запустите (старая версия заменится). Установщик не подписан: SmartScreen покажет предупреждение («Подробнее» → «Выполнить в любом случае»).

**English:** the app is now called **ccPet** (unofficial, not affiliated with Anthropic). Potentially risky usage patterns were removed: no background limit polling (one query at start and on click only; otherwise the ring is fed by Claude Code's own status line), and starting Claude Code through the Agent SDK is now opt-in and off by default. Also: the chat reopens at the last message, Settings keep their scroll position. Settings, models and hooks are kept on update. Unsigned installer.
