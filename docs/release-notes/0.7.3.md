## ccPet 0.7.3

**`/ccpet find` в Claude Code.** Питомец потерял сессию? Напишите `/ccpet find` в любой сессии: питомец заново ищет запущенные сессии, как по кнопке «Найти сессии заново» в доке. Нужен обновлённый плагин: `/plugin update ccpet`, затем `/reload-plugins` (версия 0.6.12).

**Файлы:** `ccPet_0.7.3_x64-setup.exe` (Windows), AppImage и deb (Linux), dmg (macOS). Версия 0.7.2 обновляется поверх.
