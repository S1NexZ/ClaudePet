## ccPet 0.7.2

**Панель задач не выезжает.** Клик по питомцу поверх полноэкранного видео (например, YouTube) больше не сворачивает полноэкранный режим и не выдвигает панель задач. Чат по клику на питомца открывается без захвата клавиатуры: чтобы печатать, кликните в поле ввода (по горячей клавише поле берёт фокус само).

**Файлы:** `ccPet_0.7.2_x64-setup.exe` (Windows), AppImage и deb (Linux), dmg (macOS). Версия 0.7.1 обновляется поверх.
