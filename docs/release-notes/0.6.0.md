## ccPet 0.6.0 — команды в чате, Linux и macOS (бета)

**Команды в чате**
- Ввод `/` открывает меню с подсказками (стрелки, Tab, Enter). Команды питомца: `/model`, `/btw`, `/stop`, `/new`, `/end`, `/sessions`, `/terminal`, `/usage`, `/settings`, `/help`.
- Команды Claude Code (`/compact`, `/clear`, `/cost`, `/context`, `/status`, `/memory`, `/init`, `/review`, `/resume`) печатаются в терминал сессии как есть, если у неё есть связь с обёрткой; иначе питомец объясняет, что команда там не сработает. Незнакомые `/слова` (скиллы, свои команды) уходят как набраны.

**Linux и macOS (бета)**
- Питомец работает без WSL: мост Claude Code запускается на самом компьютере. Linux: AppImage и deb; macOS: dmg и zip (Intel и Apple silicon). Сборки не подписаны.
- Терминалы открываются и поднимаются (gnome-terminal, konsole, xfce4-terminal, kitty, alacritty, xterm; Terminal.app), обёртка `claude` для bash и zsh, автозапуск на Linux.
- Автоматически проверено на GitHub Actions: тесты на Ubuntu и macOS, сборка пакетов, запуск приложения под Xvfb с подключением моста. На реальном Mac и на разных рабочих столах Linux живой проверки не было: сообщайте об ошибках в Issues.

**Прочее:** значок приложения теперь из встроенной модели (Claude娘), а не от удалённого Clawd.

**Windows:** скачайте `ccPet-Setup-0.6.0.exe` ниже. Установщик не подписан: SmartScreen покажет предупреждение.

**English:** slash-command menu in the chat (pet commands plus Claude Code commands typed into the session's terminal); Linux (AppImage/deb) and macOS (dmg/zip) betas with a native bridge, no WSL; CI-verified (tests, packaging, Linux launch under Xvfb), not tried on real macOS hardware. New app icon from the bundled default model. Unsigned builds.
