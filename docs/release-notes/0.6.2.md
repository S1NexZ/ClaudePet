## ccPet 0.6.2 — исправление удвоенных сообщений

- **Исправлено: сообщение, отправленное из питомца в терминальную сессию, приходило в Claude дважды** (текст набирался два раза подряд). Команда уходила в мост дважды из-за ошибки в маршрутизации; теперь один раз. Это касается сессий в WSL и на Linux/macOS.
- **`/model` и `/btw` работают без Agent SDK** в сессиях с терминальной обёрткой: питомец печатает строку в тот же терминал, а выполняет её сам Claude Code. `/model` без имени показывает список псевдонимов (default, opus, sonnet, haiku, opusplan). Без обёртки остаётся путь через SDK.
- **Питомец больше не пропадает с экрана**: каждые 5 с снова встаёт поверх всех окон (полноэкранное видео и игры могли опустить его), после падения отрисовки рисуется заново, после смены монитора или разрешения возвращается на экран.
- **Быстрее на долгих сессиях**: переписка читается с конца файла, а не целиком (на файле 80 МБ было около 0,85 с на каждое сообщение, стало около 15 мс).
- Кнопки «Разрешить / Отклонить» пропадают сразу, если вы ответили на запрос в терминале или приложении; несколько исправлений надёжности моста.
- Содержимое 0.6.1 (быстрая отправка в приложение Claude, Linux и macOS в бете) сохранено.

**Файлы:** `ccPet-Setup-0.6.2.exe` (Windows), AppImage и deb (Linux), dmg и zip (macOS) — по мере готовности сборок CI. Сборки не подписаны.

**English:** `/model` and `/btw` now work without the Agent SDK in sessions with the terminal wrapper (the pet types the line into the same terminal; `/model` alone lists aliases); fixed a bug where a message sent from the pet to a terminal session reached Claude twice (every chat command was delivered to the bridge twice). The pet no longer disappears (topmost re-asserted every 5 s, redrawn after a renderer/GPU crash, brought back after display changes); transcripts are read from the end (80 MB file: ~850 ms -> ~15 ms per message); the pet's Allow/Deny clears when the question is answered elsewhere; bridge reliability fixes. Everything from 0.6.1 is kept. Unsigned builds.
