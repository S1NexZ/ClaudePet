## Claude Pet 0.4.0

**Новое**
- **Несколько дистрибутивов WSL.** Питомец следит за всеми запущенными WSL 2 дистрибутивами, а не только за дистрибутивом по умолчанию (метка `WSL <имя>`, своя строка в «Подключениях»).
- **Esc, «Стоп» и ввод в Windows-сессиях.** Запускайте `claude` через обёртку `pet-helper.exe pty` (строка для профиля PowerShell копируется из «Настройки → Подключения»): окно терминала работает как обычно, а питомец может печатать и прерывать.
- **«Открыть в терминале» переводит в уже открытое окно** сессии вместо запуска клона.
- Крестик «Убрать из списка», спокойные сессии свёрнуты в «Неактивные · N», мягкие подсказки, список без мерцания.
- Мягкая тень под питомцем, аккуратная полоса прокрутки, непрозрачное кольцо лимитов.
- **Модели:** обновлённый Clawd и новая встроенная **Claude娘 (Claude-maiden)**; поддерживаются листы формата v2 (11 строк).
- Нагрузка в рабочих состояниях примерно вдвое ниже на мониторах 144 Гц.

**Установка / обновление:** скачайте `Claude-Pet-Setup-0.4.0.exe` ниже и запустите (настройки и модели сохраняются). Установщик не подписан: SmartScreen покажет предупреждение («Подробнее» → «Выполнить в любом случае»).

**Ограничения:** остановленные дистрибутивы WSL не подхватываются (мы их не запускаем); Esc/«Стоп» в Windows — только через обёртку; лимиты и новые чаты остаются за WSL; несколько дистрибутивов проверены на логике и на одном дистрибутиве, второго у разработчика не было.

**English:** the pet now follows every running WSL 2 distro; Windows sessions started through `pet-helper.exe pty claude` get Esc/Stop and typing from the pet; "Open in terminal" jumps to the already open window instead of cloning the session; dismiss cross, folded inactive sessions, soft tooltips, calmer CPU on 144 Hz displays. Unsigned installer.
