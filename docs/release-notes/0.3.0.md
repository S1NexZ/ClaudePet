## Claude Pet 0.3.0 — питомец везде, где работает Claude Code

Раньше питомец видел только WSL. Теперь он подхватывает сессии из **PowerShell / CMD / Windows Terminal, терминалов VS Code и десктопного приложения Claude** и показывает их вместе с WSL (метки `Win` / `WSL` / `App`).

**Главное**
- Чат с любой сессией без обёртки: сообщение из питомца будит сессию через фоновый хук («почтовый ящик»). Проверено на WSL и на десктопном приложении Claude.
- «Настройки → Подключения»: подключить / обновить / отключить хуки для Windows и WSL (всегда показывается diff, делается копия `.bak`, ваши хуки не трогаются).
- Ответы на разрешения прямо в питомце (по желанию, выключено по умолчанию).
- Китайский язык; компактные настройки со вкладками.
- Цветной кружок статуса (зелёный — готов, синий — думает, жёлтый — тесты, красный — разрешение/ошибка…), кольцо лимита встроено в плашку.
- Плавные анимации на GSAP, мягкая тень под питомцем, аккуратная полоса прокрутки.
- Нагрузка в покое снижена примерно с 80% до ~15% одного ядра.

**Установка / обновление:** скачайте `Claude-Pet-Setup-0.3.0.exe` ниже и запустите (настройки и модели сохраняются). Затем «Настройки → Подключения» → «Подключить» для Windows и/или WSL.
Установщик не подписан: SmartScreen покажет предупреждение («Подробнее» → «Выполнить в любом случае»).

**Ограничения:** в Windows-сессиях пока нет Esc/«Стоп» из питомца, лимитов и запуска нового чата (остаются за WSL); из WSL подхватывается только дистрибутив по умолчанию; IDE-расширения проверены только по логике. Подробности в README и CHANGELOG.

**English:** the pet now follows Claude Code sessions in Windows terminals, VS Code and the Claude desktop app, not only WSL; messages from the pet chat reach any session; permissions can be answered in the pet (opt-in); Chinese UI; calmer idle CPU. Unsigned installer (SmartScreen will warn).
