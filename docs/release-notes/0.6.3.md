## ccPet 0.6.3 — отправка в приложение Claude в фоне

- **Отправка в чат приложения Claude стала фоновой.** Питомец ждёт паузы в работе клавиатуры и мыши, делает окно приложения на время операции полностью прозрачным и забирает фокус только на вставку текста (около 120–150 мс), после чего фокус возвращается окну, в котором вы были. Сообщение в чате настоящее, ваше. Прозрачность снимается в любом случае: при ошибке, по таймауту и при следующем запуске питомца.
- Печатать в окно вообще без фокуса нельзя: Chromium не принимает ввод в неактивное окно (проверено).
- Содержимое 0.6.2 (команды `/model` и `/btw` без SDK, исправление удвоенных сообщений, питомец не пропадает с экрана, быстрее на долгих сессиях) сохранено.

**Файлы:** `ccPet-Setup-0.6.3.exe` (Windows), AppImage и deb (Linux), dmg и zip (macOS). Сборки не подписаны. Для Linux и macOS это изменение ничего не меняет: фоновая отправка работает только в Windows.

**English:** sending to a Claude app chat now works in the background (waits for an input pause, the app window is transparent during the operation, the app holds the keyboard for ~120–150 ms, focus goes straight back); everything from 0.6.2 is kept. Windows-only change. Unsigned builds.
