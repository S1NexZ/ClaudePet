## ccPet 0.7.4

**Только живые сессии.** Питомец больше не подбирает закрытые сессии и копии уже открытых. Он смотрит в реестр Claude Code (`~/.claude/sessions`) и берёт только те сессии, чей процесс ещё работает. Запущенная, но молчащая сессия тоже находится. Кнопка «Найти сессии заново» и `/ccpet find` работают по тому же правилу.

**Файлы:** `ccPet_0.7.4_x64-setup.exe` (Windows), AppImage и deb (Linux), dmg (macOS). Версия 0.7.3 обновляется поверх.
