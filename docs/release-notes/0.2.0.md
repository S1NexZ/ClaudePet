## Claude Pet 0.2.0 — первый публичный релиз

Настольный питомец для Claude Code в WSL, который делит **одну живую сессию** с вашим терминалом.

**Главное**
- Общая сессия терминала и питомца (PTY, один процесс, один транскрипт), Stop, запасной путь SDK.
- Живые лимиты подписки Claude (5 часов и неделя) раз в минуту.
- Модель Clawd по умолчанию; свои модели из ZIP или через вкладку NPM; цвета питомца и интерфейса.
- Кнопки появляются при наведении (вырастают из тени питомца); размер питомца настраивается.
- Интерфейс на русском и английском; плавные анимации; настройка разрешений для чата питомца.
- Управляемая настройка терминала без ручной правки `.bashrc`.

**Установка:** скачайте `Claude-Pet-Setup-0.2.0.exe` ниже, запустите, затем в трее подключите хуки и терминал (см. README).
Установщик не подписан: SmartScreen покажет предупреждение («Подробнее» → «Выполнить в любом случае»).

**Требования:** Windows 10/11 x64, WSL2, Claude Code в WSL, Node.js в WSL, Python 3 в WSL.
Проверено на Windows 11 + Ubuntu (WSL2), Claude Code 2.1.325, подписка Pro.

**Известные ограничения:** лимиты используют экспериментальный метод SDK; запасной путь SDK запускает второй процесс; только Windows + WSL2; интерфейс на русском. Подробности в README.
