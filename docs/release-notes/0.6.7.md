## ccPet 0.6.7 — плагин для Claude Code

**Новое: плагин ccPet для Claude Code.** Один раз введите в Claude Code (нужна версия 2.1.287 или новее):

```
/plugin install ccpet --marketplace S1NexZ/ccPet
```

- **Сообщения из питомца приходят как ваши собственные** в терминале, во вкладке Code приложения Claude и в VS Code. Без обёртки терминала, без ввода в окно приложения и без бледных вставок. Если Claude занят, сообщение само ждёт конца хода.
- **Лимиты плана питомец получает прямо от Claude Code**, без отдельных запросов.
- Плагин общается только с питомцем на `127.0.0.1`; все его действия видны в `claude plugin validate`.
- Команда установки есть в меню трея: «Плагин ccPet для Claude Code…».

Сессии WSL внутри приложения Claude плагины не загружают — для них остаются хуки, как раньше. Обновите и самого питомца до 0.6.7: плагину нужна эта версия.

**Файлы:** `ccPet-Setup-0.6.7.exe` (Windows), AppImage и deb (Linux), dmg и zip (macOS: arm64 — Apple silicon, x64 — Intel).

**English:** new ccPet plugin for Claude Code (`/plugin install ccpet --marketplace S1NexZ/ccPet`, Claude Code 2.1.287+): messages you write in the pet arrive in the session as your own (terminal, Claude app Code tab, VS Code) with no terminal wrapper and no typing into the app window, and plan limits come straight from Claude Code. Update the pet to 0.6.7 too.
