# Ручная проверка 0.7.0 (Tauri)

Отмечай результат в скобках: [ok] / [fail: что увидел]. Лог: macOS `~/Library/Application Support/Claude Pet/pet.log`, Linux `~/.config/Claude Pet/pet.log`.

## macOS (dmg, настоящий Mac)

1. Запуск: открыть dmg, перетащить в Applications, первый запуск (Gatekeeper: ПКМ → Открыть, если не подписан). Окно питомца появилось, прозрачный фон, без рамки. [ ]
2. Версия в логе: `starting 0.7.0 on macos`. [ ]
3. Трей (menu bar): иконка есть, меню открывается, «Выход» закрывает приложение и процесс. [ ]
4. Окно: питомца можно перетащить мышью (0.7.1), перетаскивание, поверх других окон, на втором мониторе/Retina масштаб не плывёт, повторный клик по иконке Dock не создаёт второе окно. [ ]
5. Мост: в логе `bridge ... ready`; `ls ~/.claude-pet/hook.sock` существует (если `claude` стоит на Mac). [ ]
6. Хуки: Настройки → Подключения → установить; показывается diff, создаётся `.bak`; запустить `claude` с коротким промптом (`Reply with exactly: ok`), питомец меняет состояние, сессия видна в списке. [ ]
7. Хуки, удаление: «Удалить» возвращает `settings.json` к исходному, чужие хуки на месте. [ ]
8. Лимиты: клик по кольцу открывает панель, один запрос, цифры показаны; повторный клик раньше 60 с новый запрос не делает. [ ]
9. Горячая клавиша Ctrl+Alt+P (или заданная) показывает/прячет окно; нужен ли доступ в «Универсальный доступ». [ ]
10. Перезапуск и автозапуск: после перезагрузки питомец на месте, позиция сохранена. [ ]

## Linux GNOME / KDE (живой десктоп, не Xvfb)

Для каждого окружения отдельно: GNOME Xorg, GNOME Wayland, KDE Plasma X11, KDE Plasma Wayland.

1. Запуск: AppImage/deb стартует, окно прозрачное, без рамки, поверх окон. [ ]
2. Wayland: если окно с рамкой, не прозрачное или не двигается, запустить `GDK_BACKEND=x11 ccpet`; зафиксировать, помогло ли. Положение окна на чистом Wayland задать нельзя: проверить, что позиция сохраняется или окно хотя бы не уезжает за экран. [ ]
3. Трей: GNOME без расширения AppIndicator трея не показывает (ожидаемо); с расширением иконка и меню работают. KDE: иконка в системном трее, меню, «Выход». [ ]
4. Клики сквозь прозрачные области проходят к окнам под питомцем, по самому питомцу и чату попадают в него. [ ]
5. Мост и хуки: как на macOS, пункты 5-7 (`~/.claude-pet/hook.sock`, установка хуков с diff и `.bak`, живая сессия). [ ]
6. Лимиты: пункт 8 из macOS. [ ]
7. Горячая клавиша: на Wayland глобальные клавиши могут не работать; записать, работает ли, и что пишет лог. [ ]
8. Масштаб: HiDPI 150%/200%, питомец не размыт, зона кликов совпадает с картинкой. [ ]
9. Закрытие: «Выход» из трея завершает процесс, `claude` в терминале продолжает жить. [ ]
