# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по [SemVer](https://semver.org/lang/ru/).

## [0.5.1] — 2026-11-17
### Добавлено
- **Проверка обновлений** раз в сутки (публичный адрес релизов GitHub, без данных о вас): уведомление и пункт в меню трея, страница релиза открывается по клику. Сам ничего не скачивает; выключается в меню трея.

### Исправлено
- **Лимиты больше не откатываются назад.** Другие сессии перерисовывали статус-строку со старыми цифрами, и они перетирали свежие. Теперь внутри одного окна лимита (одно время сброса) процент может только расти; новое окно (более позднее время сброса) заменяет старое. Работает и при записи статус-строки (WSL и Windows), и при объединении источников.
- **Статус-строка Windows не работала без Git Bash** (Claude Code тогда запускает её через PowerShell, а путь в кавычках там синтаксическая ошибка). Теперь путь записывается без кавычек и с прямыми слэшами; при запуске питомец предложит обновить строку.
- Первое сообщение нового Windows-чата больше не может попасть в уже открытую сессию в той же папке.
- Профиль PowerShell пишется в UTF-8 с BOM (или остаётся UTF-16): Windows PowerShell 5.1 читал путь с кириллицей в ANSI и обёртка ломалась. Профиль в ANSI питомец не меняет и просит добавить строку вручную.
- Короткий путь `pet-helper.exe` для путей с пробелами вычислялся неверно.
- Ожидатели ждут недоступного питомца не дольше 10 минут (не копятся), один повторный запрос на тайм-аут; `-p` в тексте подсказки или у постороннего процесса больше не принимается за `claude -p`.
- Без `pet-helper.exe` первое сообщение нового Windows-чата не теряется: оно копируется в буфер с объяснением.
- Учёт событий и сессий при нескольких дистрибутивах WSL; лишние временные файлы статус-строки.

### Изменено
- **Меньше нагрузки в покое**, внешне без изменений: цикл отрисовки спит до следующего кадра спрайта, а не работает 60 раз в секунду; свечение точки статуса — CSS-анимация прозрачности (без перерисовки); таймер анимаций GSAP переходит на 15 Гц, когда идёт только «дыхание». Замер: около 3,4% всех ядер → 0,9–1,6%.
- **Цвет дуги лимитов** всегда ваш (акцентный цвет из «Настройки → Цвета»), без автоматического жёлтого и красного; исчерпанный лимит по-прежнему «дышит».
- **pet-helper.exe запускается из постоянной копии** `%LOCALAPPDATA%\ccPet\bin`: он работает, пока живы сессии, и раньше мешал установщику заменить файлы. При первом запуске питомец предложит обновить пути в подключениях.
- Подписи в статус-строке Claude Code не зависят от языка: `5h 23% · 7d 77%` (раньше «5ч · нед»).

## [0.5.0] — 2026-11-17
Главное: десктопное приложение Claude и Windows работают как «родные» сессии.

### Десктоп Claude
- Сессии десктопа показываются под **названиями чатов** (вместо `scratch-…`), архивные чаты скрыты. Из файла сессий десктопа читаются только id, название и флаг архива.
- **«Открыть»** для такой сессии открывает именно этот чат в приложении Claude (ссылка `claude://code/continue`) и поднимает окно, без второго процесса `claude`.
- **«Стоп»** работает для десктопа, IDE и обычных Windows-терминалов: Claude останавливается после текущего шага (официальный ответ хука `continue: false`).

### Windows
- **Лимиты из Windows-сессий:** статус-строка `pet-helper.exe statusline` (ваша собственная строка сохраняется); данные WSL и Windows объединяются, показываются самые свежие.
- **Обёртка `claude` в профиле PowerShell ставится кнопкой** в «Подключениях» (изменения показываются, копия `.bak`, отмена одной кнопкой); предупреждение, если политика выполнения не даёт запускать профиль.
- **«Открыть в терминале»** поднимает вкладку самой сессии (для сессий через обёртку) вместо клона.
- **Новые чаты можно запускать в Windows** («Подключения → Где запускать новые чаты»); первое сообщение вводится в сессию, когда она появится.
- Новые Windows-сессии (в том числе VS Code) видны сразу при старте, с меткой источника; сессии не теряются при перезапуске питомца.
- При запуске питомец предлагает обновить устаревшие хуки Windows (с показом изменений).

### Подключения и диагностика
- Для каждого подключения видно время последнего события от Claude Code.
- Кнопка **«Скопировать отчёт»**: все проверки подключений одним текстом, без имени пользователя и токенов.

### Исправлено
- Пока питомец работал, разовые запуски `claude -p "…"` (Windows и WSL) не завершались: их держал ожидатель сообщений. Теперь он в таких запусках не стартует.
- Панель сессий сворачивается вместе с чатом.

### Изменено
- Встроенная модель **Clawd удалена** (это маскот Anthropic). По умолчанию теперь **Claude娘 (Claude-maiden)**; если у вас был выбран Clawd, питомец переключится на неё сам. Clawd можно поставить вручную как свою модель.
- Кружок статуса и кольцо лимитов одного размера и стоят ровно при любом масштабе экрана.

## [0.4.1] — 2026-11-17
### Безопасность и правила Anthropic
- **Убраны потенциально небезопасные способы использования.** Регулярный опрос лимитов раз в минуту через Agent SDK удалён. Запрос теперь выполняется только один раз при запуске и по вашему клику на кольцо (не чаще раза в минуту); в фоне кольцо питается строкой состояния Claude Code. Запуск второго процесса `claude` через Agent SDK (новые чаты из питомца, продолжение терминальных сессий, /btw, список моделей) **выключен по умолчанию** и включается флажком с предупреждением. Токены и учётные данные питомец по-прежнему не читает и не хранит.
- Название изменено на **ccPet** («cc» — сокращение от Claude Code, не знак связи с Anthropic).

### Изменено
- **Лимиты.** Кольцо показывает только дугу (цифры в подсказке при наведении), по клику открывается панель с одним свежим запросом; один такой запрос делается и при запуске. Подключение строки состояния — в «Настройки → Подключения → лимиты через статус-строку» (с diff и копией файла; ваша собственная строка не теряется: питомец оборачивает её и при отключении возвращает как была).
- **Новый чат** при выключенном Agent SDK открывает новую сессию Claude Code в терминале (с первым сообщением), питомец видит её через хуки.
- Переименование: `ccPet.exe`, `ccPet-Setup-<версия>.exe`. Папка настроек `%APPDATA%\Claude Pet`, `~/.claude-pet` и каталог установки не менялись: настройки, модели и подключённые хуки сохраняются. Старые сообщения с пометкой «Claude Pet» в транскриптах по-прежнему распознаются.

### Исправлено
- Чат при повторном открытии показывает последнее сообщение, а не начало.
- Настройки больше не прокручиваются вверх после изменения внутри вкладки.

## [0.4.0] — 2026-11-17
### Добавлено
- **Несколько дистрибутивов WSL**: кроме дистрибутива по умолчанию питомец следит за всеми запущенными WSL 2 дистрибутивами (проверка раз в 30 с; остановленные не запускаются). У каждого свой мост и свой порт хуков (все дистрибутивы делят одну сеть), сессии в общем списке с меткой `WSL <дистрибутив>`, в «Подключениях» своя строка для каждого.
- **Esc, «Стоп» и ввод из питомца в Windows-сессиях** через обёртку `pet-helper.exe pty claude` (ConPTY): окно терминала работает как обычно, а питомец пишет и жмёт Esc через именованный канал (доступен только вашему пользователю). Строка для профиля PowerShell копируется из «Настройки → Подключения».
- «Открыть в терминале» переводит в уже открытое окно (или вкладку Windows Terminal) этой сессии вместо запуска копии `claude --resume`; если живого терминала нет, открывается новое окно, как раньше.
- Крестик «Убрать из списка» у строк сессий; «Завершить» больше не отказывается убирать сессию, процесс которой уже закрыт.
- Спокойные сессии (спят, простаивают, готово более 5 минут назад) свёрнуты в строку «Неактивные · N», которая разворачивается.
- Мягкие подсказки вместо серых системных; строки списков обновляются на месте (без мерцания при наведении).
- Мягкая тень под питомцем, тонкая полоса прокрутки, непрозрачное кольцо лимитов.

- Новые встроенные модели: **Clawd** (обновлённый, SVG-версия godxxy1229) и **Claude娘 (Claude-maiden)**. Поддерживаются листы формата v2 (1536×2288, 11 строк) наравне с 8×9.

### Изменено
- Нагрузка: интерфейс и GSAP ограничены 60 кадрами в секунду (на мониторах 144 Гц это снижает нагрузку в рабочих состояниях примерно вдвое).

## [0.3.0] — 2026-11-17
### Добавлено
- **Универсальная интеграция**: питомец видит сессии Claude Code не только в WSL, но и в PowerShell/CMD/Windows Terminal, терминалах VS Code и десктопном приложении Claude (HTTP-хуки на `127.0.0.1:47821`); у каждой сессии метка `Win` / `WSL` / `App`.
- **Чат с любой сессией** без PTY через «почтовый ящик»: фоновый `asyncRewake`-хук (`pet-helper.exe` на Windows, `pet-hook.mjs wait` в WSL) будит сессию текстом из питомца. Проверено на живой простаивающей сессии WSL и десктопного приложения.
- **Настройки → Подключения**: статус по хостам, Подключить / Обновить / Отключить хуки (всегда с diff и копией `.bak`, ваши хуки не затрагиваются).
- **Разрешения в питомце** (по желанию, выключено по умолчанию): Разрешить / Отклонить через хук `PermissionRequest`; без ответа за 30 с остаётся обычный диалог Claude Code.
- Запущенные сессии находятся по свежим транскриптам ещё до первого хука.
- Китайский язык интерфейса; компактные настройки с вкладками (в т. ч. «Подключения»).
- Статус в виде цветного кружка (зелёный — готов, синий — думает, жёлтый — тесты, красный — разрешение/ошибка и т. д.), слово выезжает при наведении; легенда в настройках. Кольцо лимита встроено в плашку статуса.
- Редактор RGB остаётся открытым, пока вы его не закроете.
- Анимации на GSAP: панели выезжают из питомца и сворачиваются, прерываемые таймлайны.
- Мягкая тень под питомцем и тонкая скруглённая полоса прокрутки.

### Изменено
- Нагрузка в покое снижена примерно с 80% до ~15% одного ядра (окно по высоте контента и подвешено к питомцу, тяжёлая работа с DOM ~15 Гц, «дыхание» ступенчатое).
- Панели открываются под питомцем; окно не сдвигает питомца и не возвращает его назад при перетаскивании.
- Убрана «вторая Мику» на пару кадров при открытии панелей.

## [0.2.0] — первый публичный релиз
### Добавлено
- Общая живая сессия Claude Code между терминалом и питомцем (PTY-обёртка `pet-claude.py`, unix-сокет, один процесс и один транскрипт); Stop и обнаружение Esc/Ctrl+C из терминала.
- Живые лимиты подписки (5 часов и неделя) через `get_usage` Agent SDK, обновление раз в минуту короткими процессами, без перекрывающихся запросов; состояния «свежие / устарели / недоступны».
- Модель по умолчанию **Clawd** (с удалением светлой каймы); прежняя Shy Miku больше не поставляется, её можно установить как свою модель.
- Кнопки (чат, настройки, сессии) скрыты: под питомцем лежит тень, а при наведении из неё вырастает плашка с кнопками. Размер питомца 60–180% (ползунок в настройках или меню трея).
- Интерфейс на русском и английском (по языку системы или вручную в настройках).
- Плавные анимации (кросс-фейд кадров, мягкий «поп» при смене состояния, «дыхание» в покое; отключается при «уменьшить движение»), счётчик лимита показывает 100 и замыкается.
- Разрешения для чата питомца: спрашивать / правки без вопросов / всё без вопросов (по умолчанию спрашивать); сессии в списке сворачиваются (3 ч покоя → сон, потолок 15).
- Настройки: цвет питомца и акцентный цвет с мгновенным предпросмотром и сохранением.
- Менеджер моделей: выбор и предпросмотр без перезапуска, установка из ZIP с проверкой (защита от выхода за пределы папки, ссылок, «бомб», скриптов), вкладка NPM (сторонний `codex-pets`), удаление с подтверждением.
- Управляемая настройка терминала: `install-shell-integration.sh` (diff, подтверждение, резервная копия, откат) и пункт трея «Подключить терминал (WSL)…».
- Документация: README, приватность, диагностика, уведомления о сторонних компонентах; лицензия MIT.

### Исправлено
- Запасной путь SDK продолжает сессию в исходной папке и не продолжает молча в копии (`resumeCwd`, проверка session ID).
- Диалоги подтверждения: Enter теперь выбирает безопасную кнопку.
- Запись ответа в чат после Stop; состояние после прерывания Esc.
